Indicadores do módulo energético

Este HTML usa resultados gerados por calculos.py, a mesma função do Streamlit. Para trazer outras entradas, importe o JSON exportado pelo dashboard ou baixe a apresentação diretamente por ele.

Abrir dashboard local

O dashboard local precisa estar iniciado com python -m streamlit run app.py. Este HTML funciona offline.

Energia atendida e déficit

Mesma quantidade de pontos e horário; consumo em kWh no período selecionado.

Investimento estimado

Equipamentos + provisão de instalação; separado dos custos de operação.

Comparação das alternativas

B é isolado e não compra da rede. Se houver déficit, o menor gasto não representa economia para o mesmo serviço. Reservas são provisões financeiras, não despesas medidas.

Fluxo de funcionamento

Energia proposta e dados manuais. Sem controle físico, sensores, IoT ou medição em tempo real.

Equipe, fontes e premissas

    Não há cálculo de CO₂, retorno de investimento, custo em dez anos ou compensação na rede. Esses itens não fazem parte do modelo atual.

    A contribuição de SERS compara LED na rede e LED solar com bateria. Sensores, dimerização e geração no quiosque do arquivo de origem foram substituídos para corresponder ao protótipo atual. Veja o repositório do projeto.

    Como apresentar

    1. Use as setas para passar as cenas. F alterna tela cheia.
    2. R mostra as notas. Grave só a apresentação quando as notas estiverem ocultas.
    3. Na demonstração, compare referência e ensaio com 1 HSP. Para usar o Streamlit, abra o dashboard local com o Python iniciado.
    4. Publique o vídeo como não listado e preencha o link no arquivo de entrega. O HTML não publica o vídeo.
